## 概要

`yoloinspect` は、YOLO11を使用して画像に写っている物体を検出するコマンドです。

画像ファイルを指定すると、検出された物体の種類と個数を集計して表示します。

標準入力とコマンドライン引数の両方に対応しています。

## 主な機能

- 画像ファイルから物体を検出
- 検出した物体の種類と個数を集計
- 標準入力から画像ファイルのパスを受け取り可能
- コマンドライン引数から画像ファイルを指定可能
- 信頼度しきい値を指定可能
- 不正な入力や画像ファイルのエラー処理

## 必要環境

- Ubuntu 20.04 以降
- Python 3.8 以降
- pip
- Ultralytics
- PyTorch

## インストール

以下のコマンドで必要なライブラリをインストールします。

```bash
pip install ultralytics
```

初回実行時にYOLO11nの学習済みモデルが自動的にダウンロードされます。

## 使用方法

### 1. 画像ファイルを直接指定

```bash
./yoloinspect test_image.jpg
```

### 2. 標準入力から画像を指定

```bash
echo "test_image.jpg" | ./yoloinspect
```

### 3. 信頼度しきい値を指定

```bash
./yoloinspect -t 0.7 test_image.jpg
```

しきい値は0.0から1.0の範囲で指定できます。

値を大きくすると、より高い信頼度の検出結果だけが表示されます。

## エラー処理

- 画像ファイルが存在しない場合はエラーを表示します。
- 画像ファイルが指定されていない場合はエラーを表示します。
- 信頼度しきい値が0.0から1.0の範囲外の場合はエラーを表示します。
- 不正な入力が指定された場合はエラーを表示します。

## 自動テスト

以下のコマンドで自動テストを実行できます。

```bash
chmod +x test_yoloinspect.bash
./test_yoloinspect.bash
```

以下の5項目をテストします。

- 通常の画像ファイルの検出
- 存在しない画像ファイルのエラー処理
- 不正なしきい値のエラー処理
- 画像パス未指定時のエラー処理
- 標準入力からの画像パス指定

すべて成功すると、PASS: 5、FAIL: 0 と表示されます。

GitHub Actionsにより、mainブランチへのpushおよびpull request時に自動テストが実行されます。
